# 双策略市场模拟候选

用户确认总本金为 100 万 USD，其中 50 万用于激进热点追板，50 万用于稳健长期策略，并委托设计风险数字。以下是第一版模拟研究参数，不是经优化的最优参数或收益承诺。进度与验证只在 [BACKLOG](BACKLOG.md) 维护。

## 参数与用途

所有仓位百分比以**各自策略池当前净值**为分母，两个池分别审批、记账和计算回撤，不互相借款、转移持仓或自动补仓。

| 参数 | 激进热点池 | 稳健长期池 |
| --- | --- | --- |
| 初始模拟本金 | 500,000 USD | 500,000 USD |
| 首次建仓建议 | 本池 5%，初始约 25,000 USD | 本池 6%，初始约 30,000 USD |
| 单一发行人上限（合并跨市场证券） | 10%，初始约 50,000 USD | 12%，初始约 60,000 USD |
| 单研究主题上限 | 25% | 25% |
| 最低已结算现金 | 净值的 40%，初始约 200,000 USD | 净值的 20%，初始约 100,000 USD |
| 单批次价格下跌退出复核线 | 相对成交价 -5% | 相对成交价 -12% |
| 盈利后的回撤复核 | 已记录浮盈达 8% 后，从已记录高点回撤 4% | 已记录浮盈达 20% 后，从已记录高点回撤 8% |
| 本池净值回撤预警 / 停止新增买入 | 6% / 10% | 10% / 15% |
| 持有复核截止上限 | 10 个自然日 | 365 个自然日 |
| 订单有效期上限 / 行情允许延迟 | 15 分钟 / 30 秒 | 60 分钟 / 60 秒 |
| 每笔单边费用 / 不利滑点研究假设 | 10 bp / 5 bp | 10 bp / 5 bp |
| 隔夜持有 | 允许，仍受可卖时间限制 | 允许，仍受可卖时间限制 |

建议首次建仓比例用于人工设计，当前不是自动开仓或强制首单额度。仓位上限、主题上限、现金底线则参与每次批准和成交前检查；已批未成交买单的数量及预算也占用额度。主题按研究 ID 统计，尚不能识别不同研究实际上同属一个宏观主题。发行人合并依赖执行适配器提供经核验的统一身份。

保留现金使激进池在初始状态最多约 60% 投入证券、稳健池最多约 80% 投入证券。单笔激进首次仓位在理想 -5% 退出价格下约损失 1,250 USD；这是设计尺度，不是保证损失上限。价格跳空、涨跌停、排队、费用、FX 和卖出限制都可能扩大损失。

## 买入与退出

激进池第一版将“只追涨停板”落实为**A 股主板普通股的已核验 10% 涨停**，排除 ST、新股特殊期及其他板块。这个范围是开发假设，未覆盖所有涨停制度。执行适配器必须同时给出证券身份、适用规则、当日涨停价、卖盘、排队后可成交数量及其核验状态；仅有涨停价、总成交量或封单量均不能证明自己可以买到。只在涨停价成交，不能把配置滑点加到法定上限之外；排队风险通过未成交与部分成交表达。没有可靠数据时保持未成交。

稳健池建议按基本面证据、估值空间和失效条件选择分散的长期仓位，避免把热点池持仓自动复制过去。当前系统保存人工交易假设和研究版本，尚未实现自动基本面选股或估值质量评分。所谓“稳健”是策略意图；全部投入股票仍可能有较大波动。分散不保证在整体市场下跌时免受损失，见 [Investor.gov](https://www.investor.gov/introduction-investing/investing-basics/save-and-invest/diversify-your-investments)。

单批次价格退出线按证券原币成交价和**实际检查时已记录的高点**计算；本池回撤按含已结算/未结算现金与持仓估值的 USD 净值计算，包含已扣费用及汇率变化。系统并不假装观察到了检查间隔内的盘中最高价。估值缺失时显示未知，不能用 0 回撤代替。

单票触线或到期后提示退出复核，并阻止继续增加该证券仓位；本池达到回撤暂停线时暂停新买入。暂停状态持久保存，恢复到阈值以内后仍需本人说明并显式恢复。**不会自动生成已获批卖单或自动卖出**；需本人提交并批准退出申请，再等待可卖时间、报价和可成交数量。触发价不保证成交价，参见 [FINRA 对止损订单的说明](https://www.finra.org/investors/insights/stop-orders-factors-consider-during-volatile-markets)。

## 报价与账本

现有公开日线/分钟收盘价只用于研究，不能直接成为执行报价。服务端 `marketInputs` 保留为合成测试的依赖注入接口；正式入口新增私有执行数据包桥接，由 `SIGNAL_EXECUTION_CONFIG` 显式配置。尚未选择或启用真实供应商，观察行情不会自动进入该桥接。浏览器不能提交报价、FX、成交或直接修改余额。离线演示不允许创建市场账户。每个研究实例的两个账户须本人分别勾选确认初始化，各自本金固定为 50 万 USD；原 100 万场景账本是独立演练，不与这两个账户相加形成 200 万的策略资产。

批准前保存研究快照、配置版本、策略版本和市场核对指纹。数据变化后须重新核对；审批以前的报价不能拿来成交。过程支持等待、部分成交、全部成交、拒绝、撤销、过期和版本失效；任何成交都在同一事务内记录订单、现金、持仓、费用、FIFO 成本和共享流动性消耗。两个账户不能重复消费同一报价的可成交量。报价实际时刻相同但时区写法不同，仍共享同一份数量；价格或其他内容改变时等待新快照。新成交使用版本2标记，旧版计数在使用前与冻结成交核对，旧历史保持原样。含旧记录的首次新时点检查会扫描旧计数与账本，尚未验证大型旧账本的长期耗时。升级后不支持旧程序继续写同一个库；如需回退，使用升级前的独立备份。

金额使用十进制定点计算，到账时四舍五入到 USD 分；买入成本包含费用，卖出先扣费用再计算已实现损益。可卖时间和现金结算时间分别由适配器提供，避免将“可卖”与“结算到账”混为一谈。当前只是 USD 计价模拟账本，没有真实换汇或多币种现金子账户。

每次成功命令有幂等标识、乐观版本检查、完整状态快照及 SHA-256 前序链接；重启保留。历史不会被配置调整重写。哈希链便于检查一致性，不抵御拥有数据库写权限者重新生成整条链。配置改变使未结束申请失效，已成交部分保留。恢复副本仍遵守既有恢复核对门禁。

支持本人点击“检查订单、成交与结算”推进；后续候选增加默认暂停的持久自动模拟执行，在“查看状态”启用后约每10秒检查两个池。暂停自动执行不禁用手动检查；账户随工作台刷新，草稿保留。详见[运行说明](DEPLOYMENT.md#自动模拟执行)。分项费用计算和私有执行数据包桥接已实现；真实供应商连接、适用的完整市场日历与税费来源核对及长期策略评估未完成。不得把合成测试收益当作策略收益。模型继续使用本机 Codex 入口，本次未安装独立本地模型。

## 日参考汇率与研究换算

增加欧洲央行日参考汇率来源，固定读取官方 XML 的 USD、CNY、HKD 对 EUR 原值，按 `USD/EUR ÷ 原币/EUR` 换算美元。来源只给日级日期，不虚构精确发布时刻；保存原始XML、SHA256、解析版本、请求/获取时刻和不可变快照。同日源修订另存版本，同一内容保留首次获取信息；重复请求标识不再联网，失败须用新标识明确重试，最少间隔一分钟。

[ECB来源说明](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)指出这些参考汇率只供信息用途，不宜用于交易。因此此功能独立于市场成交接口和账本净值：明确标记 `executable: false`，模拟风控拒绝用它替代成交FX。报价、真实换汇成本、税费、队列及流动性仍须合格适配器。当前只提供后端接口，没有自动任务或新页面，也不自动更新账户。

在研究实例中，可使用以下本地接口（沿用工作台的同源与JSON请求保护）：

- `POST /api/reference-fx/refresh`，正文仅 `{ "requestId": "fx-review-001" }`，标识须8–80位英文字母、数字、连字符或下划线；地址和汇率不可由客户端指定。
- `GET /api/reference-fx` 返回当前可用参考快照、最近20份历史和获取结果，不向页面返回原始XML。当前表示已取得且来源日期非未来的最新版本，并不代表实时或交易有效期内。
- `GET /api/reference-fx/convert?currency=CNY&amount=1000` 做研究换算；支持USD、CNY、HKD及最多6位小数的非负金额，可用 `snapshotId` 指定已保存旧版本。返回原始比率、来源日期和快照ID，以精确整数比率一次四舍五入到USD分。

来源日期倒退和未来文件留档；未来版本不能用于当前换算，正常后续响应不被未来文件阻塞。离线演示和未确认恢复副本不能更新，启动/查询不联网。旧换算可用精确快照重现；该接口不接受任意历史回测时点，不能声称某日参考值在当天开盘前已可获得。完整实时FX和长期来源健康仍未完成。

## 执行输入的精确时间

执行报价、FX、交易时段、可卖与结算时间接受带时区的ISO时间，秒后支持1–9位小数。时间比较和流动性身份使用整数纳秒，原始输入文本继续保存在成交快照；不先截断到毫秒。时区别名和多余小数零表示同一时刻，真正不同的亚毫秒报价分别识别。此前毫秒输入的版本2缓存键及规范化指纹保持一致，无需重写旧成交或缓存。用户填写的订单期限仍沿用既有毫秒契约。

来源适配仍需保留供应商的数量单位、覆盖市场、行情权限、延迟、状态及规则依据。例如[Alpaca官方股票流文档](https://docs.alpaca.markets/us/docs/real-time-stock-pricing-data)列明报价数量使用round lots、时间可到纳秒，SIP与IEX等feed有不同范围且访问受订阅约束。这些字段说明不是本项目已有权限或已接通的证明；不能把手数直接当股数，也不能仅凭买卖盘数量推断涨停排队后的可成交量。本批未选择或启用供应商、订阅服务、换汇或交易接口。


## 私有执行输入桥接

正式研究入口可设置 `SIGNAL_EXECUTION_CONFIG`，指向本人私有配置的绝对路径。配置和数据包须为当前用户拥有的普通文件，权限不开放给组或其他用户（建议0600），不能是文件符号链接；配置上限64KiB、包上限4MiB及80只证券。供应商适配器负责按实际权利取得数据、转换为股数，并以私有临时文件和原子重命名更新包；浏览器不能上传价格、FX、规则、费用、容量或成交。

这是一条规范化输入桥接，**不是已接通的行情/券商客户端，也不会自动购买订阅或认证供应商许可**。`permission.reviewed` 是操作人核对具体协议后的声明。尚无协议、容量或完整费用证据时不能将未知字段改成true来通过检查。

配置结构为 `execution-feed/1`，包含 `id/source/framePath`、`permission` 和 `capabilities`。权限必须记录 `id/sourceDocument/validFrom/validUntil/markets`，`usage` 固定为 `paper-execution`；市场只接受CN、HK、US。能力需显式声明 `quantityUnit: shares`、核对过的 `identityVerified/rulesVerified/fxVerified/feesVerified`，容量为 `verified-allocatable` 或 `verified-after-queue`。期限到期后不读取新包，缓存也不能继续用于执行。

包结构为 `execution-frame/1`，包含同一 `source`、`packetId` 和 `quotes` 数组。每条保留已有市场输入契约：规范证券代码/币种、统一发行人、报价/接收/有效期、bid/ask/mark、交易状态/时段、申报和部分成交单位、可卖及结算时刻、规则版本。另须 `rulesVerified/capacityVerified`，FX须标记 `executable:true`、对应原币 `currency` 和 `baseCurrency:USD`，并附下述完整费用方案。A股涨停排队后的容量还需配置能力、`queueVerified` 与 `queueEvidence` 同时满足；显示买卖盘、总成交量及普通OHLC都不能推导自己的可成交量。

收到的完整包原文、SHA256、首次接收时刻及接受/拒绝结果保存在研究库 `execution_input_frames`；当前规范化版本另存 `execution_input_state`。同内容且同权限配置不重复写历史；权限配置变更时保留新旧配置和核对结果。重复证券取消该证券本包输入，其他证券逐条核对；格式/读取失败清空当前可执行输入，不能继续使用上一成功包成交。已批准依据和已成交快照保留包指纹、权限配置指纹及原数据。变更来源权限配置、规则版本或费用方案会阻止旧批准继续成交，须重新申请。恢复锁与任务暂停仍在读取后、提交前复核。

查询 `GET /api/execution-feed` 仅返回配置、来源、权限时效、包指纹、接收及拒绝数量；不返回本机路径或原包。`POST /api/execution-feed/refresh` 正文必须为空对象，沿用实例/同源保护。手动检查订单和自动execution任务均先刷新桥接再撮合；其他公开研究行情与参考FX入口保持独立。

## 分项费用与部分成交

执行桥接要求 `execution-fees/1` 方案，记录 `id/version/source/currency/validFrom/validUntil`、`verified/complete` 及1–20个费用组件。每个组件记录来源、买卖方向（buy/sell/both）、按成交额基点/每股/固定额（notional-bps/per-share/fixed）、计费范围（per-fill/per-order）、舍入（nearest/ceil）和原币步长（quantum），可有最低和封顶。`complete:true` 只能在核对适用市场、证券、交易方向及本人经纪商全部收费后设置，不代表本软件独立鉴证。

金额以原币十进制定点计算，微单位以下的正费用在向上舍入前保留；组件舍入后分别按执行FX换算USD分。最低/封顶在舍入后仍保持边界。每单组件累计收费，部分成交只收累计差额，最低费和封顶不重复收费；每次成交冻结分项原币金额、USD金额、版本和来源。买入预算及成交前风控计入分项费用，卖出净额扣费后按适配器给出的时刻结算，现金、费用累积、FIFO与容量同事务提交。无源费用方案的旧合成输入沿用配置feeBps，旧成交不被重算；启用桥接后分项方案覆盖界面的演练bp。

市场和经纪商收费不能用统一10bp替代。例如香港收费存在买卖方向、原币及舍入要求，见[HKEX交易费用](https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Trading/Transaction?sc_lang=en)和[结算费用](https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Clearing-and-Settlement/Operational?sc_lang=en)；美国2026年4月4日起的SEC适用销售费率见[官方公告](https://www.sec.gov/rules-regulations/fee-rate-advisories/2026-2)。本批不预填未经经纪商和适用证券核对的完整税费方案。

在prototype运行 `npm run execution:verify -- <私有配置绝对路径> <全新输出目录绝对路径>` 可用同一桥接核心核验当前包，生成0600报告。该命令只开内存库，不访问正式研究库、HTTP服务、模型或账户；报告不输出原包与本机配置路径。不覆盖已有输出目录。接受输入不等于真实成交或供应商权利验收，账号自身仍重新检查更短的报价允许延迟、限价、仓位及本人批准。
