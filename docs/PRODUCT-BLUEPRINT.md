# 产品设计基线与 1.0 RC 路线

2026-10-08 用户要求按完整产品规划逐项实施，目标为 `v1.0.0-rc.1`。本文件保存设计和验收契约；**实现进度只在 BACKLOG.md 更新**，版本标签不证明功能或真实数据验收已完成。

## 产品主线

定时批量采集与留档 → 事项与重大事件 → 证据和公司影响 → 条件化行动建议 → 本人最终决定 → 订单 / 持仓 → 定时复核与退出 → 独立评估。

2026-10-12 收尾范围修订：按用户要求，采用定时批次，不要求实时抓取或全天连续处理。到时运行一轮，普通缺口记录后继续其他对象；失败有限重试，剩余问题延至后续批次，不要求本人处理中间卡点。复用已有周期任务，不新建复杂调度系统。本次不擅自设置新的运行时间、改正式实例频率或新增系统定时服务。

首页保持现有五区，优先展示最近一轮结果、数据时间、重大事件、公司判断、持仓盈亏和风险；运行状态按等待下次、执行中、完成、部分失败表达，详细日志在原运行详情展开。旧的秒级内部队列检查不等于外部实时抓取承诺；以后调整采集频率也不联动放宽订单有效期或行情有效性判断。

**收尾验证从简：**复用输入、程序和环境仍适用的已有证据；修改处做定向检查，交付候选按项目规则完成必要检查。不为文案或文档重跑全量代码测试，不新增同目的的负载、故障矩阵和多版本接续实验。长期定时采集与 1/5/20 交易日效果积累转入后续运营评估，不再作为本次工程收尾的等待条件；未成熟就显示未评估，不据此声称盈利有效。证券身份、引用、账本、报价和数据保护的正确性仍是必需项。

正常采集、补证、归并、研判与监控由后台推进。本人查看依据、走势与风险后决定买卖。输入不足自动转观察；常规中间失败隔离、有限重试或延后，不转成人工流水线。同一材料与模型调用限次；已启用的周期采集与监控持续按退避检查，保留失败历史与来源冷却，不在连续三次失败后永久停掉；主动暂停、取消及恢复核对锁仍优先。原有人工确认、研究版本与订单批准记录保留。系统生成的研究不伪装为人工核验。

范围：本地单用户，A股、港股、美股研究，首版本人确认实际 / 手动模拟成交记录并跟踪持仓。实际记录、手动模拟、后续行情自动撮合与场景演练独立核算。真实券商下单、做空、采购或公开托管不由此目标授权。

## 首版范围修订 · 2026-10-12

用户确认首版采用本人确认成交记录，行情自动撮合后置。组合页默认进入“确认成交记录”，复用逐笔账本；实际记录与手动模拟分别核算、保留原始版本，研究与退出跟踪继续自动进行。手动模拟只说明假设成交，不证明市场可成交。无可靠价格时，当前浮盈亏和回撤显示未知；已实现损益按已确认金额、成本和费用核算。自动撮合及其供应商、部分成交、结算与执行容量验收不再阻塞首版。旧方案中冲突部分以RC-D210及本节为准。

## 页面与交互契约

- 保留深色风格、工作台 / 组合 / 评估主导航和现有走势图。
- 首页五区：整体状态；重大事件；当前研判与走势；全局风险 / 买卖待决定 / 后续监控；常驻持仓与退出摘要。
- 首页显示总数与重点条目，完整列表由“查看更多”承接。事件选择只高亮关联持仓，不能隐藏其他账户或持仓风险。
- 组合默认确认成交记录，可在实际记录 / 手动模拟间选择；持仓仍在首页常驻。行情自动撮合置于高级入口，参数与场景演练折叠。
- 评估分研究质量、信号后价格、模拟结果、历史回测与前向验证。日后价格变化不是策略收益。
- 研究详情沿用摘要、证据、公司与行情、行动、历史五组。长阅读进完整详情；短操作用一个侧栏，避免叠层。
- 短依据原位展开；持仓一次展开一行。下拉只选择范围，不触发采集、模型或交易。查看更多继承筛选。
- 返回恢复事件、账户、筛选、图表周期、展开和滚动位置。后台更新不抢选中项；旧行动方案失效必须即刻标明。
- 设置与运行详情承接来源、模型、预算、规则、任务、备份及技术日志。日常首页只显示关键结果与影响。
- 桌面检查基线为 1280×720、1440×900；窄屏风险与状态、持仓摘要优先，表格仅在局部滚动。

## 数据契约

- 材料 / 事项、事件 / 主题、企业 / 上市证券、研究 / 行动方案、订单 / 持仓批次分别具有稳定身份和版本关联。
- 新闻保留发布、首次获取、修订和可读范围；聚合发现源不等于独立证据源。
- 重大性、证据可靠性和可行动条件分别表达。主张概率不等于股价上涨概率。
- 公司建议必须说明主体、证券、传导机制、敞口、量级、时间与反证；歧义不进入确定行动方案。
- 进入条件、目标区间、逻辑失效、价格风险、持有窗口与下次复核分别命名；缺依据不生成精确价位。
- 持仓显示成本、现价及时间、浮盈亏、原研究与当前判断、退出窗口 / 条件、风险和下一复核。
- 未初始化、缺价格 / FX / 成本或历史时显示未知，不把缺失显示为 0。实际记录缺现金流时不称完整账户收益。
- 当前回撤 / 最大回撤注明账户、窗口和采样；记录高点不代表未采到的盘中高点。回测、价格影响和成交收益分开。
- 读模型是现有来源、研究、任务和账本的投影，不复制业务状态。所有判断、失败、无信号、拒绝、未成交及亏损均留样。
- 站内结果标记按对象与建议版本去重；已读不等于风险解除、已批准或已成交。

### v0.14 的实施顺序与持仓口径

沿用首页持仓账户下拉、原位单行展开、持仓详情和“组合”页面，不再增加一级导航。以下为实施契约，完成状态以 BACKLOG 为准。

1. **先接实际记录。** 组合页提供批量导入预览与单条补记；输入只代表本人提供的持仓 / 成交记录，不是订单。按账户、市场、证券和记录身份区分，证券代码歧义不能自动归到另一市场。预览显示新增、重复、冲突和缺失；确认只保存所见版本。重传不重复记账，修正追加历史并保留原始批次；失败不留下半批记录。
2. **再接可核对的盈亏。** 持仓快照与成交明细分别标识；只有数量与成本快照时先展示持仓浮盈亏，不反推已实现收益。成本保留提供者、日期、币种和含费口径；未知费用、汇率或现金流不默认补零，不套用演练资金。先按原币核算；跨币种汇总须有明确的汇率快照，缺失时分别显示。缺乏完整现金流时不展示完整账户净值、收益率或最大回撤。
3. **接回同一研究上下文。** 首页能从实际账户查看数量、成本、价格及时间、盈亏、关键风险和退出复核；展开保留原交易依据和当前判断，再进入原研究 / 公司走势。多事件命中同一证券时展示关联依据，不按标题猜一个建仓理由。后续研究变化追加监控记录，不改写原成本、成交或建仓依据。
4. **后台定时复核。** 持仓成为长期跟踪对象，每轮即使无新新闻也检查可用价格、期限和已有退出条件。缺价格记为无法判断，反证、期限到达或条件命中进入首页风险 / 复核摘要。提醒按对象与条件版本去重；查看或标为已读不等于风险解除。模拟退出进入既有本人决定流程；实际记录不向券商提交订单。
5. **最后贯通条件方案与退出账本。** 自动研究在证券身份、来源、价格、账户、数量和风险条件都明确时形成可核对的方案；缺口自动转观察并继续补证。方案绑定输入与有效期，旧批准不能用于新版本。首版实际与手动模拟买卖均以本人确认记录更新，核对费用、成本及退出后的持仓；自动撮合与部分成交验证后置。回测、信号后价格变化、模拟收益和实际记录各自独立展示。

实际数据的首次导入 / 修正是账户事实输入，不新增逐条新闻筛选、归组或分析审批。日常仍是看首页结果、按需追问依据、最后决定买卖；未接通的数据不会通过模型或演示值自动补齐。

### 已确认的质量覆盖边界

按RC-D212，首版明确披露A股/港股研判质量和独立留出样本尚未验证，后续按定时样本继续评估，不以等待这两项阻塞RC。美股同样只声明已复核公开样本的有限质量范围；没有总体准确率或盈利证明。A05/A12/A13保留归属、身份、引用、当时可用时间、固定版本、留出隔离和完整分母的工程要求，不将后置评估伪装成通过。

## 1.0 后续路线

1. **首版研究与确认记录：**完成上述A01–A16在修订范围内的必要核对，整理一个安装与恢复可审阅候选。独立质量缺口明确披露，模型输出不得冒充已核验事实。
2. **1.0 RC → 1.0：**修复候选审阅中的实际问题，确认包与说明一致；精确候选获批后再发布，不因路线图自动上传或部署。
3. **后续行情增强：**单独选择并核验参考行情来源，提高定时估值覆盖；再接入合格执行行情、模拟自动撮合、部分成交及三市场执行规则。范围、费用和权限届时明确。
4. **后续定时积累：**按既有机制设置采集和持仓复核日程，逐步形成来源稳定性、研究质量及1/5/20交易日结果；不追求实时或全天运行，不以未成熟结果宣称盈利。
