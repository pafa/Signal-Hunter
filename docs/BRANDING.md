# 名称与产品表述

- 中文名称：**信号猎手**。
- 英文名称：**Signal Hunter**。
- 中文定位：**重大事件研究与模拟交易工作台**。
- English description: **Event Research & Paper Trading Workbench**.
- 一句话介绍：从新闻变化，到可复核的交易假设。
- 本地 npm 包标识：`signal-hunter-workbench`，保留 `private: true`。

本项目作为本地源码工具分发，不依赖独立域名、在线托管或 npm 包发布。README 是产品介绍和使用入口。

名称由项目发起者于 2026-09-27 确定。产品名称不改变已有数据库路径、事件 ID、API、环境变量或历史记录。本项目与其他同名产品无关联；不主张名称独占。

对外表述应区分“当前实现”“场景演练”和“未来目标”，不以自动重大事件识别、实时成交、已验证收益或模型有效性描述尚未完成的能力。公开图示使用范围见 [图片说明](assets/README.md)。
